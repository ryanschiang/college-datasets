Common Data Set

Collected and prepared by our Enrollment Analytics team, the Common Data Set consists of admissions- and enrollment-related data about Northwestern University. We report this information in a standard format in collaboration with higher education peers. It includes:
  • General information
  • Enrollment and persistence
  • First-time, first-year (freshman) admission
  • Transfer admission
  • Academic offerings and policies
  • Student life
  • Annual expenses
  • Financial aid
  • Instructional faculty and class size
  • Degrees conferred
If you have specific questions regarding the Common Data Sets posted here, please email our Enrollment Analytics team at enrollmentanalytics@northwestern.edu. For more information on the Common Data Set initiative, please visit the official Common Data Set website.
